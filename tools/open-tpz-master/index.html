Release & availability

Open TPZ Master v0.1.0 — Initial Public Release

Open TPZ Master is an open-source desktop tool for SAP PI/PO consultants, designed to simplify message mapping analysis and provide a visual representation of mapping dependencies.

Download

The initial public release, v0.1.0, is available through GitLab.

View Release v0.1.0 on GitLab

Visit the release page to access available downloads, source code archives, and release notes.

Features

  • SAP PI/PO message mapping analysis
  • Interactive mapping dependency visualization
  • Target structure navigation and search
  • Standard function and UDF identification and source code
  • Target field search

Availability

Open TPZ Master is distributed through its official GitLab repository. Future versions, improvements, and bug fixes will be published through GitLab Releases.

The project is currently in its early development stage. Features and compatibility may change between versions.
