Training ERP GUI

A desktop learning tool for explaining ERP integration concepts through familiar, transaction-style screens.

I built Training ERP GUI to support hands-on lessons with a junior consultant. It gives us a visual way to discuss configuration, message processing and monitoring, using a Python application built with PySide6.

Explore the screens Training scenarios

Why I built it

When teaching integration, explaining a configuration field in isolation is rarely enough. It helps to show where the field appears, how it relates to other settings and where a consultant would look when investigating a message.

This project turns those conversations into practical demonstrations. Learners can follow a screen-based workflow while the lesson focuses on the meaning of the configuration and the questions to ask.

What you can explore

The application includes training screens inspired by common SAP integration transactions. The focus is on presenting their concepts and workflows in an educational desktop interface.

Connections and communication settings

  • SM59-style screens: discuss RFC destinations and connection configuration.
  • WE21-style screens: introduce ports used in IDoc communication.
  • WE20-style screens: explain partner profiles and their role in an integration setup.

Messages, testing and monitoring

  • WE19-style screens: introduce the structure of an IDoc testing workflow.
  • SM58-style screens: discuss transactional RFC monitoring concepts.
  • SPROXY-related views: support lessons about proxy-based integration.
  • IDoc and proxy monitoring views: demonstrate selection criteria, result tables and message-oriented investigation.

Configuration examples

JSON-backed example data and configuration provide a practical foundation for the training screens. They make it possible to prepare lesson content and discuss how screen inputs relate to stored values.

How I use it in training

1. Explain an IDoc configuration

Walk through destination, port and partner-profile concepts. Ask the learner what each setting represents and how the pieces relate to the communication scenario.

2. Practise a monitoring conversation

Start with selection criteria, display example results and discuss what to inspect next. The goal is to help the learner build an investigation process rather than simply memorize screen names.

3. Connect interface fields to configuration data

Use a configuration screen and its JSON representation to demonstrate how entered values can be collected, stored and loaded by an application.

Built with

  • Python for application logic.
  • PySide6 / Qt for desktop windows, forms and tables.
  • JSON for example data and configuration.

Scope of the project

Training ERP GUI is an independent educational project. Its screens illustrate selected integration concepts; they do not reproduce the full behavior of SAP transactions or constitute a complete ERP system.

On-screen examples should not be treated as evidence of a transaction running in a live SAP backend. Practical work in a real environment remains part of learning configuration, authorizations and runtime behavior.

This project is not an official SAP product and is not affiliated with or endorsed by SAP.
